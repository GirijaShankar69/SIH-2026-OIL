> physics-calibrated synthetic datasets generated from first-principles reservoir engineering

## 📁 Dataset 1 — Baghewala Reservoir & Geological Calibration Dataset

**Source:** Published geological surveys of the Jodhpur Sandstone Formation, Bikaner-Nagaur Basin, Rajasthan + Oil India Limited EOR Reports.

**Used To Train / Calibrate:** Boberg-Lantz Thermal Reservoir Model, Marx-Langenheim Steam Chamber Growth, and Multiphase Heavy Oil IPR.

**Generated File:** `core/data/sample_data_generator.py → WELLS_METADATA`

| Parameter | Value | Unit | Source |
|-----------|-------|------|--------|
| Formation | Jodhpur Sandstone (Unit A/B) | — | Bikaner-Nagaur Basin Survey |
| Depth | 950 – 1,100 (nominal 1,050) | m | OIL Drilling Reports |
| Net Pay Thickness | 15.0 – 22.0 (nominal 18.0) | m | Core Analysis Logs |
| Porosity | 0.22 – 0.26 (nominal 0.24) | fraction | Core-plug measurements |
| Permeability | 150 – 450 (nominal 280) | mD | Pressure build-up tests |
| Native Reservoir Temperature | 46.0 – 48.0 (nominal 47.0) | °C | BHT surveys |
| Native Reservoir Pressure | 100 – 115 (nominal 110) | bar | DST tests |
| Crude Oil Gravity | 17.0 – 19.0 (nominal 18.2) | °API | Crude assay |
| Native Dead Oil Viscosity | 2,500 – 3,500 | cP @ 47°C | Viscometry lab |
| Rock Density | 2,400 | kg/m³ | Core analysis |
| Overburden Thermal Conductivity | 1.80 | W/(m·°C) | Literature (shale caprock) |
| Overburden Thermal Diffusivity | 0.85 × 10⁻⁶ | m²/s | Literature |

## 📁 Dataset 2 — SARA Fluid Characterization & PVT Dataset

**Source:** Published crude assay data for Bikaner-Nagaur Basin 18° API crude + standard PVT correlations.

**Used To Train / Calibrate:** Herschel-Bulkley Rheology Model, Walther-Andrade Viscosity Model, Asphaltene Colloidal Instability Index (CII), Emulsion Viscosity Multiplier.

| SARA Fraction | Weight % | Role in Model |
|---------------|----------|--------------|
| **Saturates** | 34.0 wt% | Paraffinic light fraction |
| **Aromatics** | 29.5 wt% | Solvent carrier for asphaltenes |
| **Resins** | 22.0 wt% | Asphaltene stabilizing peptizers |
| **Asphaltenes** | 14.5 wt% | High-MW polyaromatic core |
| **Colloidal Instability Index (CII)** | **0.94** | CII > 0.90 → High deposition risk |
| Asphaltene Onset Temperature | 68.0 | °C |
| Bubble Point Pressure | 38.0 | bar |
| Solution GOR | 14.0 | sm³/m³ |

**Viscosity-Temperature Calibration Points (Andrade Model):**

| Temperature (°C) | Viscosity (cP) | Measurement Method |
|-----------------|----------------|-------------------|
| 47 (Native) | 2,650 | Rolling ball viscometer |
| 70 | 620 | Rotational viscometer |
| 100 | 145 | Rotational viscometer |
| 140 | 42 | Capillary viscometer |
| 180 | 24 | Capillary viscometer |
| 220 (Steam Temp) | 18 | High-temperature viscometer |

**Download the dataset:**
```python
import numpy as np, pandas as pd
temps = [47, 70, 100, 140, 180, 220]
visc  = [2650, 620, 145, 42, 24, 18]
sara  = {'Saturates_wt%': 34.0, 'Aromatics_wt%': 29.5, 'Resins_wt%': 22.0, 'Asphaltenes_wt%': 14.5}
pd.DataFrame({'temperature_c': temps, 'viscosity_cp': visc}).to_csv("jury_dataset_2_pvt_viscosity.csv", index=False)
pd.DataFrame([sara]).to_csv("jury_dataset_2_sara_composition.csv", index=False)
```

## 📁 Dataset 3 — Dynamometer Card Training Corpus (AI Classifier Dataset)

**Source:** Fully synthetic, generated by solving the **Gibbs 1D Damped Wave Equation** (finite difference PDE solver) across a calibrated parameter grid representing Baghewala Field conditions.

**Used To Train:** Random Forest Dynamometer Card AI Diagnostic Classifier (8-class).

**Dataset Dimensions:**
- **Total Samples:** 112 fully simulated dynamometer card cycles
- **Points per Card:** 120 discretized load-displacement coordinates (surface + downhole = 240 points/card)
- **Feature Vector Dimension:** 12 engineered geometric + Fourier features per card
- **Classes:** 8 operating regimes

**Parameter Space Swept:**

| Parameter | Values Swept | Count |
|-----------|-------------|-------|
| Reservoir Temperature | 48, 70, 110, 160, 210 °C | 5 |
| In-Situ Viscosity | 18, 80, 250, 800, 2200, 3200 cP | 6 |
| Pumping Speed (SPM) | 3.5, 5.0, 6.5, 8.0, 8.5 SPM | 5 |
| Pump Fillage Fraction | 0.50, 0.70, 0.85, 0.95, 0.98 | 5 |
| Fault Injections | Normal, Rod Float, Fluid Pound, Gas, Unanchored, TV Leak, SV Leak, Overload | 8 |

**Class Distribution:**

| Class | Label | Physics Condition | Count |
|-------|-------|-------------------|-------|
| 0 | Normal Fillage | fillage ≥ 0.85, no float, low drag | 18 |
| 1 | Severe Rod Floating | F_drag/W_buoy ≥ 0.70 | 16 |
| 2 | Fluid Pound | fillage < 0.60 | 14 |
| 3 | Gas Interference | Gas void fraction > 0.15 | 12 |
| 4 | Unanchored Tubing | High card tilt covariance | 12 |
| 5 | Traveling Valve Leak | Low upstroke gradient | 14 |
| 6 | Standing Valve Leak | Negative load dip | 12 |
| 7 | High Viscous Overload | μ > 1500 cP, high PPRL | 14 |
| **Total** | | | **112** |

**Download the dataset:**
```python
from core.ml.dyno_card_classifier import baghewala_card_classifier
import pandas as pd

# Export training features and labels
X = baghewala_card_classifier.training_features  # shape (112, 12)
y = baghewala_card_classifier.training_labels    # shape (112,)
labels = baghewala_card_classifier.class_names

feature_names = [
    'card_area_normalized', 'mprl_pprl_ratio', 'centroid_x', 'centroid_y',
    'downstroke_min_dip', 'impact_spike_amplitude', 'tilt_covariance_skew',
    'fourier_harmonic_1', 'fourier_harmonic_2', 'fourier_harmonic_3',
    'upstroke_slope', 'peak_load_normalized'
]
df_X = pd.DataFrame(X, columns=feature_names)
df_X['class_id'] = y
df_X['class_label'] = [labels[i] for i in y]
df_X.to_csv("jury_dataset_3_dynocard_training.csv", index=False)
print(f"Exported {len(df_X)} training samples × {len(feature_names)} features")
```

## 📁 Dataset 4 — CSS Production History & Optimization Dataset

**Source:** Physics-simulated from Boberg-Lantz + Marx-Langenheim + Darcy-Vogel models for 6 wells × 6 cycles × 120 days = 4,320 daily time-steps.

**Used To Train:** Physics-Informed CSS Production Surrogate Model, Multi-Objective Pareto Optimizer.

**Columns in Dataset:**

| Column | Description | Unit |
|--------|-------------|------|
| `well_id` | Well identifier (BGW-01 to BGW-15) | — |
| `cycle_number` | CSS cycle number (1–6) | — |
| `steam_volume_cwe_m3` | Injected steam (Cold Water Equivalent) | m³ |
| `soak_days` | Soak period duration | days |
| `day_in_cycle` | Production day (1–120) | days |
| `reservoir_temperature_c` | Reservoir average temperature | °C |
| `sandface_temperature_c` | Sandface temperature | °C |
| `oil_viscosity_cp` | In-situ dead crude viscosity | cP |
| `reservoir_pressure_bar` | Current reservoir pressure | bar |
| `oil_rate_bopd` | Daily oil production | BOPD |
| `water_cut` | Produced water fraction | fraction |
| `cum_oil_bbl` | Cumulative oil produced | bbl |
| `cumulative_sor` | Cumulative steam-oil ratio | m³/m³ |
| `steam_cost_usd` | Steam generation cost | USD |
| `npv_usd` | Net present value of cycle | USD |

**Download the dataset:**
```python
from core.data.sample_data_generator import generate_well_telemetry, WELLS_METADATA
import pandas as pd

all_dfs = []
for meta in WELLS_METADATA:
    df = generate_well_telemetry(meta['well_id'], days_count=120)
    df.insert(0, 'well_id', meta['well_id'])
    all_dfs.append(df)

full_df = pd.concat(all_dfs, ignore_index=True)
full_df.to_csv("jury_dataset_4_css_production_history.csv", index=False)
print(f"Exported {len(full_df)} rows × {len(full_df.columns)} columns")
```

## 📁 Dataset 5 — Sucker Rod Fatigue & Historical Failure Log Dataset

**Source:** Calibrated from API RP 11L Grade D rod string mechanical specifications + Baghewala field failure taxonomy records.

**Used To Train:** Goodman-Miner Cumulative Fatigue Damage Model, Predictive Maintenance RUL Engine, Pump Unsetting Probability Sigmoid.

**Sucker Rod Mechanical Properties (API Grade D):**

| Property | Value | Unit |
|----------|-------|------|
| Tensile Strength (S_ult) | 115,000 | psi (793 MPa) |
| Elastic Modulus (E) | 30 × 10⁶ | psi |
| Density (ρ) | 7,850 | kg/m³ |
| Service Factor (SF, corrosive thermal) | 0.90 | — |
| Top taper diameter | 7/8 in | — |
| Top taper cross-section area | 0.6013 | sq in |
| Bottom taper diameter | 3/4 in | — |
| Bottom taper cross-section area | 0.4418 | sq in |
| Hold-down pump seating force | 4,200 | lbs |

**Baghewala Historical Failure Taxonomy:**

| Failure Type | Depth | Root Cause | Count in Log |
|-------------|-------|-----------|--------------|
| Rod Parting | 620 m | Impact shock fatigue (>12,000 lbs) | 14 |
| Hold-down Pump Unseating | 1,010 m | Fluid hammering under rod float | 8 |
| Rod Pin Fatigue | 450 m | High mean stress + impact cycles | 6 |
| Asphaltene Valve Plugging | Tubing | Crude < 64°C wellhead temperature | 11 |
| Rod Buckling | 800–1,050 m | Excessive downstroke compression | 4 |
| Traveling Valve Seal Erosion | Pump | High sand/asphaltene abrasion | 7 |
